# 文献笔记模板（复制到个人库「10-文献笔记」下使用）

> 使用说明：每读一篇论文，复制本模板，把标题改成论文名，按下面小节填。带 `（...）` 的是提示，填完删掉。
> 目的不是抄论文，而是**用自己的话记下"它解决了什么、怎么做的、对我有什么用"**，方便以后快速回顾。

---

# （论文标题）

- **作者：** ｜ **期刊/会议：** ｜ **年份：**
- **DOI / 链接：**
- **标签：**（如 #精读 #方法可借鉴 #待复现）

## 一句话概括
（这篇论文干了啥，一句话说清。）

## 解决的问题
（研究背景 + 动机，别人为什么没解决。）

## 方法
（核心思路、模型/算法，用自己的话讲，别大段抄原文。）

## 关键结论 / 结果
（主要发现、实验数据、对比效果。）

## 可借鉴的点
（对我有什么用：方法能迁移？代码能复用？写作/画图能学？）

## 我的疑问 / 备注
（没看懂的地方、想深入的方向。）
